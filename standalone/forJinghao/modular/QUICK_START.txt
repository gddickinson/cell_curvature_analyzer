================================================================================
🔧 CUSTOMIZE PARAMETERS:
================================================================================

Create a JSON config file (e.g., my_config.json):

{
  "analysis": {
    "n_points": 15,
    "depth": 250,
    "width": 80,
    "movement_threshold": 0.15,
    "temporal_direction": "past"
  }
}

Then use it:
python 03_calculate_movement.py input output --config my_config.json

================================================================================
📁 WHAT GETS CREATED:
================================================================================

Step 1 Output:
  - loaded_data.npz (images + masks as NumPy arrays)
  - data_info.json (metadata and validation report)
  - data_visualization.png (sample frames)

Step 2 Output:
  - edges.npz (contours for each frame)
  - edge_statistics.json (edge lengths, empty frames)
  - edge_detection.png (edges overlaid on masks)

Step 3 Output:
  - movement_data.npz (movement scores, types, maps)
  - movement_summary.json (statistics)

All .npz files can be loaded with: np.load('file.npz')
