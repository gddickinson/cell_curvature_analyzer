================================================================================
INDIVIDUAL STEP USAGE
================================================================================

STEP 1: Load and Validate Data
-------------------------------
python 01_load_and_validate.py <image_path> <mask_path> <output_dir> [--visualize]

Outputs:
  - loaded_data.npz (images and masks)
  - data_info.json (metadata)
  - data_visualization.png (if --visualize)

STEP 2: Detect Edges
---------------------
python 02_detect_edges.py <input_dir> <output_dir> [--visualize]

Requires: loaded_data.npz from Step 1

Outputs:
  - edges.npz (contours for each frame)
  - edge_statistics.json
  - edge_detection.png (if --visualize)

STEP 3: Calculate Movement
---------------------------
python 03_calculate_movement.py <input_dir> <output_dir> [--config config.json] [--visualize]

Requires: loaded_data.npz, edges.npz

Outputs:
  - movement_data.npz
  - movement_summary.json

STEPS 4-7: (Templates to be completed)
---------------------------------------
These follow similar patterns and will process:
  - Step 4: Sample intensity at edge points
  - Step 5: Correlate movement with intensity
  - Step 6: Generate comprehensive visualizations
  - Step 7: Export final CSV and JSON results

================================================================================
CONFIGURATION
================================================================================

Create custom configuration files in JSON format:

{
  "analysis": {
    "n_points": 12,              # Number of sampling points
    "depth": 200,                # Sampling rectangle depth
    "width": 75,                 # Sampling rectangle width
    "min_cell_coverage": 0.8,    # Min overlap with mask
    "movement_threshold": 0.1,   # Movement classification threshold
    "temporal_direction": "past" # "past" or "future"
  },
  "output": {
    "save_detailed_csv": true,
    "save_summary_json": true,
    "save_correlation_plots": true,
    "save_frame_plots": true
  },
  "visualization": {
    "plot_every_nth_frame": 10,
    "movement_cmap": "RdBu_r",
    "intensity_cmap": "viridis",
    "figure_dpi": 150
  }
}

Save as config.json and use with:
python 03_calculate_movement.py input output --config config.json

================================================================================
UNIT TESTING
================================================================================

Every module has built-in unit tests:

# Test without visualization
python utils/config.py --test

# Test with visualization  
python utils/edge_detection.py --test --visualize

# Test with your own data

The tests create:

  - Visual outputs (PNG files) when --visualize is used

================================================================================
INTERMEDIATE DATA FILES
================================================================================

loaded_data.npz
  - images: (N, H, W) array
  - masks: (N, H, W) array

edges.npz
  - frame_0, frame_1, ...: (M, 2) contour arrays

movement_data.npz
  - transition_*_movement_score: float
  - transition_*_movement_type: string
  - transition_*_movement_map: (H, W) array
  - transition_*_displacements: 1D array
  - transition_*_x_positions: 1D array

(intensity_data.npz, correlation_data.npz to be added in steps 4-5)
